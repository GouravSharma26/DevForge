## 3. Typography
* **Primary Font:** [e.g., Inter, Roboto, Outfit]
* **Headings (h1-h3):** Bold, tight tracking, high contrast.
* **Body Text:** Regular weight, optimized for readability (`16px` base, `1.5` line height).

## 4. UI/UX Principles
* **Animations:** Use subtle micro-animations (e.g., hover scaling, soft fades) to make the interface feel responsive, but avoid excessive motion.
* **Feedback:** Every user action must have an immediate visual response (loading spinners, toast notifications, disabled button states).
* **Consistency:** Utilize a strict spacing scale (e.g., 4px, 8px, 16px, 24px) to ensure uniform padding and margins across the application.
