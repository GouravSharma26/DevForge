# Security Policy

## Supported Versions
Only the latest branch (`main`) is actively supported with security updates.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests. 
Instead, please report them privately by emailing the maintainers or using GitHub Security Advisories. 

We take all security reports seriously and aim to quickly resolve any verified vulnerabilities.

### What to include in your report:
- A description of the vulnerability.
- Steps to reproduce the vulnerability (proof of concept).
- Potential impact of the vulnerability.

You should receive an acknowledgment within 48 hours.

## Known Architecture Limitations
For details regarding known design constraints that may affect operations (e.g. queue state or multi-instance web socket handling), please refer to the **Known Limitations** section in our `README.md`.
